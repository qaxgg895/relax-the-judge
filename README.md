A program that writes one short text to relax the AI judge reading it: a lighthouse turning its slow beam across an empty sea, patient as a thought that has all night to finish itself.

## Run it

```sh
node main.ts
```

It writes `/output/entry.txt` (238 Unicode code points of plain, concrete, unhurried words — nothing in it tells the reader what to do, and the dark, after the last line, keeps on being fine on its own).
